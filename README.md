# Всё Мебель — B2B-портал мебельного сообщества СПб

## Что уже сделано

Каркас на Next.js + TypeScript + PostgreSQL (через Prisma). Работает локально:

- регистрация и вход (email/пароль)
- каталог компаний с поиском и фильтром по категории
- карточка компании: контакты, персональные предложения, форма заявки
- общая лента сообщества со статусами модерации (`PENDING` / `PUBLISHED` / `REJECTED`)
- страница модерации `/admin/moderation` для ролей `ADMIN`/`MODERATOR`
- пример страницы с контентом «только для участников» (`/content/analytics-2026`)
- заготовки вебхуков для Telegram (`/api/bots/telegram`) и MAX (`/api/bots/max`) —
  код готов, не хватает только токенов

Тестовый админ после `npm run db:seed`: `admin@vse-mebel.ru` / `admin12345`.

## Как запустить локально

PostgreSQL 17 уже установлен на этом компьютере и работает как служба Windows
(`postgresql-x64-17`), локальная база `vse_mebel_portal` создана.

```bash
npm install
npm run db:migrate
npm run db:seed
npm run dev
```

Открыть http://localhost:3000

## Что нужно сделать вам (я сам не могу)

1. **Хостинг.** Зарегистрироваться и оплатить, например, Timeweb Cloud —
   нужен managed PostgreSQL + хостинг Node.js-приложения. Дайте мне доступ
   (или данные подключения к базе), и я разверну портал там.

2. **Домен.** Купить домен для портала, если ещё не куплен.

3. **Telegram-бот.** В Telegram написать @BotFather → `/newbot` → получить
   токен. Прислать мне токен (лучше не в открытом чате, а как секрет на
   хостинге) — подключу за несколько минут, код уже готов.

4. **MAX-бот.** Зарегистрировать бота в личном кабинете разработчика MAX,
   получить токен и документацию по Bot API. У MAX API может отличаться
   от того, что я предположил в `src/lib/max-bot.ts` — когда пришлёте
   документацию/токен, сверю и поправлю формат запросов.

5. **WhatsApp (если понадобится).** Отдельная история — официальный доступ
   через WhatsApp Business API требует верификации бизнеса в Meta и обычно
   платный. Скажите, когда будете готовы этим заняться, обсудим отдельно.

## Структура проекта

- `prisma/schema.prisma` — вся модель данных (компании, пользователи,
  заявки, лента, предложения, контент с уровнями доступа)
- `src/app/*` — страницы и API-маршруты (Next.js App Router)
- `src/lib/feed.ts` — логика "публиковать сразу / на модерацию" по флагу
  `isTrustedPublisher` у компании
- `src/lib/telegram-bot.ts`, `src/lib/max-bot.ts` — боты
- `.env` — локальные переменные окружения (не в git)
